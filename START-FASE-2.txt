PASO 4 — MCP server: bccr

- src/index.ts: servidor MCP stdio que expone 2 herramientas:

PASO 5 — MCP server: hacienda-cr

- src/index.ts con 2 herramientas:

  - consultar_factura({ clave_numerica: string }) - llama al endpoint de estado de FE de Hacienda. Si falla auth o no se puede llamar sin token, devolvé { estado: 'no_consultado', motivo: 'auth_pendiente' } sin tirar.
